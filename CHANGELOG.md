# jsal.ui 0.3.8

- **Shopping list:** adding a recipe from a profession window opens the list right beside it, so it never hides behind them. If you already have the list open somewhere, it stays there.
- **Shopping list:** in a recipe's details, the count and "Add to shopping list" now sit along the bottom, clear of the game's favourite star.
- **Profession window:** long recipe names stop before the skill numbers instead of running into them.
- **Craft timer:** lines up with the profession window's right edge.
- **Favourites at trainers:** the trainer's own list keeps its recipe names in full while the panel is open.
